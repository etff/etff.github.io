* [그림으로 배우는 HTTP & Network](http://www.yes24.com/Product/Goods/15894097) - www.yes24.com

 웹개발을 하는데 웹을 더 이해해야한다는 생각을 많이 갖고 있습니다. 그림으로 배우는 HTTP & Network는 웹개발하시는 분들이 읽으면 좋을 것같습니다. 이분야 최고는 HTTP 완벽가이드라고 생각하지만, 필요한 HTTP 지식과 그림을 통한

이해는 이 책이 좋은 것같습니다.

특히 HTTP 헤더, 프로토콜, 구조 부분이 그림으로 되어있어 그림과 해설을 읽으면서 도움을 많이 받았습니다.

네트워크의 구조를 공부하고 싶으면 후니의 쉽게 쓴 시스코 네트워킹을 읽는것을 추천하고, 이 책은 웹쪽이면 특히 각종 위키의 방대한 프로토콜 정리나 HTTP 완벽가이드의 무게에 포기했다면 먼저 이 책을 접하는 것도 좋을 것같습니다.

책의 목차 정리가 잘 되어있어 참고하고 싶을때 찾기 쉽게 편집해둔것도 마음에 듭니다.
